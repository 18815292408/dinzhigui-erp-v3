# 定制大师 使用指南

---

## 一、这个系统是做什么的？

定制大师是一套帮助定制家具门店管理日常业务的系统。从客户进门到安装交付，每个环节都可以在系统里跟进，让门店老板、店长、设计师、导购、安装师傅各司其职，协作完成每一笔订单。

简单来说，系统管三件事：**客户、订单、进度**。

---

## 二、开始使用

### 2.1 登录

打开系统网址（由管理员提供），用手机号或邮箱登录即可。

密码由管理员在创建账号时设置。

### 2.2 你的角色是什么？

系统里有五种身份，每个人看到的页面和能做的事情都不一样：

| 角色 | 能做什么 |
|---|---|
| **老板** | 看所有数据，管账号，关键操作（收款、回退等） |
| **店长** | 基本跟老板一样，可以管理日常业务和人员 |
| **设计师** | 接单、做方案、提交方案、向工厂下单 |
| **导购** | 录客户、建订单、派单给设计师 |
| **安装师傅** | 更新安装进度、填发货/到货/安装信息 |

刚开始使用时，由老板或店长帮大家创建账号。

### 2.3 账号过期怎么办？

如果登录时提示"账号已过期"，说明这个账号的有效期到了，联系老板或店长处理即可。

## 三、核心流程：一笔订单从头到尾怎么走？

这个是整个系统最重要的部分。一笔订单从签下来到安装完成，一共要经过 **8 个步骤**：

```
① 待派单  →  ② 待接单  →  ③ 设计中  →  ④ 待下单
⑤ 待打款  →  ⑥ 待出货  →  ⑦ 安装中  →  ⑧ 已完成
```

---

### 第一步：待派单 —— 这笔单子谁来做？

**谁来做**：老板 / 店长 / 导购

导购跟客户签完单，订单就进了系统，这时候还没指定设计师。老板或店长需要把订单**派给某个设计师**。

操作很简单：打开订单详情，点「派单」，选一个设计师，确定就行。导购也可以派自己签的单。

派完之后，被选中的设计师会收到一条通知。

---

### 第二步：待接单 —— 设计师确认接手

**谁来做**：设计师

设计师收到通知后，进入订单详情，点「接单」，然后选一个设计完成时间（7天、10天、12天或15天），确认接单。

接单后系统会自动创建一条方案记录，设计师就可以开始干活了。

> 设计周期只能从 7、10、12、15 天中选，不能自己填。

---

### 第三步：设计中 —— 设计师出方案

**谁来做**：设计师

设计师在这个阶段做方案：
- 在「方案管理」里创建方案，填写房间数、面积、描述、预估价格
- 上传图纸、效果图等附件
- 方案做好后提交

系统会帮忙盯进度：**截止前一天会提醒**，如果**超期了也会通知**。

---

### 第四步：待下单 —— 方案好了，准备向工厂下单

**谁来做**：设计师

方案提交后，订单进入"待下单"状态，表示方案已经确认，可以联系工厂生产了。

这时设计师需要在订单详情里点「提交方案」，系统会把订单推进到下一步。

---

### 第五步：待打款 —— 向工厂下单，等客户付款

**谁来做**：设计师 / 老板 / 店长

这是关键一步。操作人在订单详情点「工厂下单」，选择合作工厂、填好金额，确认下单。

> **注意**：这一步要求订单必须已经填了**成交价**。如果成交价没填，系统会阻止下单，并通知导购去补填。成交价填的是"万元"（比如 3.5 就是三万五）。

下单完成后，就等客户打款了。

---

### 第六步：待出货 —— 客户付了钱，准备发货安装

**谁来做**：老板 / 店长

客户付款后，老板或店长在订单详情点「确认收款」。这时候可以顺便把安装师傅也指定好，也可以先不指定，后面再说。

确认收款后，订单进入"待出货"状态。

---

### 第七步：安装中 —— 师傅上门干活

**谁来做**：安装师傅 / 老板 / 店长

这个阶段是整个安装过程的跟踪，分几个小步骤：

```
待发货 → 已发货 → 已到货 → 配送中 → 安装中 → 补件 → 已安装
```

安装师傅每完成一步，就在系统里点「更新状态」，选当前的进度。

> 状态只能往前走，不能退回（比如已经到了"已到货"，就不能退回到"已发货"）。唯一的例外是"补件"：任何时候发现缺件少料，都可以跳到"补件"状态，系统会自动通知设计师处理。

---

### 第八步：已完成 —— 大功告成

**谁来做**：老板 / 店长

安装全部完成、客户验收后，老板或店长在订单详情点「完成订单」。这笔订单就归档了，可以在「已完成订单」页面随时查看。

---

### 特殊情况：订单需要回退怎么办？

有时候操作失误或者情况有变，需要把订单退回到上一步。只有老板和店长可以操作，在订单详情点「回退」即可。

| 回退前 | 退回到 | 会发生什么 |
|---|---|---|
| 待接单 | 待派单 | 取消设计师分配 |
| 设计中 | 待接单 | 取消设计师分配 |
| 待下单 | 设计中 | 方案变回草稿 |
| 待打款 | 待下单 | 清除工厂下单记录 |
| 待出货 | 待打款 | 清除安装记录 |
| 安装中 | 待出货 | 清除安装记录 |
| 已完成 | 安装中 | 订单重新激活 |

## 四、各个页面怎么用？

### 4.1 首页看板

打开系统第一眼看到的就是看板。这里展示：
- 每个阶段有多少订单（点进去就能看到具体订单）
- 智能分析（老板和店长可见）：系统自动分析哪些订单卡住了、哪里钱压着没回来、这周签了多少单，还会给出行动建议
- 月度统计（老板和店长可见）：每月收入、成本、利润

### 4.2 客户管理

录客户信息的地方。姓名、电话、地址、户型、装修需求都可以填。还可以标记客户意向高低，记录每次跟客户的沟通情况。

页面分成两个标签：**有活跃订单的客户**和**暂无订单的客户**，方便区分跟单重点。

### 4.3 方案管理

设计师做方案的地方。创建方案时要关联客户和订单，填写房间数、面积、方案描述、估价，可以上传图纸和效果图。

方案可以按订单状态筛选，快速找到哪些是待处理的、哪些是进行中的。

设计师只能看到分配给自己相关的方案。

### 4.4 安装管理

管理所有安装任务。能看到每单的发货、到货、配送、安装进度，可以填反馈和问题记录。

进入这个页面时，系统会自动检查有没有"漏掉"的安装任务，有的话会自动补上。

### 4.5 已完成订单

所有做完的订单都在这里归档，随时可以翻看历史记录、关联的方案和安装信息。

### 4.6 工厂管理（仅老板/店长）

管理合作工厂的名录：工厂名称、联系人、电话、地址。

### 4.7 消息中心

系统会在关键节点自动发通知，分几种情况：

- 被分配了新任务（派单、安装等）
- 任务快到期或已超期
- 有人提交了方案、确认了收款
- 需要补件

通知可以点进去直接跳到相关订单。设计师点通知还能直接在弹窗里接单。

### 4.8 账号管理（仅老板）

老板在这里管理团队成员的账号：添加新员工、设置有效期。

## 五、常见问题

**Q：为什么不能工厂下单？**

A：先检查订单的成交价填了没有。成交价必须大于 0 才能下单，这是系统强制要求的。

**Q：设计师接单时为什么天数不能自己填？**

A：设计周期目前只支持 7、10、12、15 天四个选项，选一个就行。

**Q：安装状态点错了怎么办？**

A：正常情况不能回退，但可以从任何状态跳到"补件"。联系老板或店长操作回退也可以。

**Q：订单能删除吗？**

A：如果已经有方案或安装记录了就不能删，需要先处理关联记录，或联系老板/店长操作。

**Q：登录提示"账号已过期"怎么办？**

A：联系老板或店长，帮你延长账号有效期。

**Q：不同的人看到的页面为什么不一样？**

A：这是正常的，系统按角色分配权限：
- 老板和店长能看到所有功能
- 设计师只能看到跟自己相关的方案和订单
- 导购只能操作自己创建的客户和订单
- 安装师傅只能看到分配给自己的安装任务

## 六、业务小贴士

1. **金额怎么填？** 系统里的金额都用"万元"作单位。比如成交价三万五，填 `3.5` 就行。系统会自动换算和显示。

2. **订单编号怎么看？** 每个订单有一个编号，格式是 `DD-日期-序号`，比如 `DD-20260428-001` 表示 2026 年 4 月 28 日的第 1 单。

3. **忘了填成交价？** 导购创建订单时最好就把成交价填上，否则后面工厂下单会被卡住。如果被卡了，系统会自动发通知提醒导购补填。

4. **谁该做什么？** 顺着订单流程走就行——导购签单 → 老板派单 → 设计师接单做方案 → 老板收款 → 师傅安装。每一步系统都会发通知，跟着通知走就不会漏。
