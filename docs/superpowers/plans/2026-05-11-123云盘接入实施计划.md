# 123云盘接入实施计划

## 项目背景

方案管理系统当前使用 Supabase Storage 存储 CAD 文件，面临两个问题：
1. 文件上传大小限制仅 150MB，需要提升至 500MB
2. Supabase 存储容量不足，需迁移至 123云盘

## 技术调研结果

### 123云盘开放平台 API 概览

| 项目 | 详情 |
|------|------|
| 官方文档 | https://123yunpan.yuque.com/org-wiki-123yunpan-muaork/cr6ced |
| API 基础域名 | https://open-api.123pan.com |
| 认证方式 | ClientID + ClientSecret → AccessToken |
| 单文件上传限制 | 单步上传 1GB，大文件需分片上传 |
| 分片上传 | 支持，SDK 自动处理 |
| 存储容量 | 取决于账号类型（普通用户 2TB 起） |
| 下载流量 | 免费用户 10GB/月，VIP 不限 |
| 现有 SDK | `@ked3/pan123-sdk` (npm) |

## 实施步骤

### 步骤 1：账号注册与配置（需用户配合）

1. 访问 https://www.123pan.com/developer 注册开发者账号
2. 购买开发者权益包（开通 API 调用权限）
3. 获取 `client_id` 和 `client_secret`
4. 在 `.env.local` 中添加配置：
   ```
   PAN123_CLIENT_ID=your-client-id
   PAN123_CLIENT_SECRET=your-client-secret
   ```

### 步骤 2：安装 SDK

```bash
npm install @ked3/pan123-sdk
```

### 步骤 3：创建 123云盘服务层

新建文件：
- `src/lib/pan123/client.ts` - SDK 初始化和 Token 管理
- `src/lib/pan123/upload.ts` - 上传封装（支持进度回调）
- `src/lib/pan123/download.ts` - 下载/获取直链封装

### 步骤 4：修改后端 API

修改文件：
- `src/app/api/upload/sign/route.ts` - 改为生成 123云盘上传签名
- `src/app/api/upload/route.ts` - 保留或直接上传备选
- `src/app/api/upload/complete/route.ts` - 新增：上传完成回调

### 步骤 5：修改前端上传组件

修改文件：
- `src/components/designs/design-edit-form.tsx`
  - 文件大小限制改为 500MB
  - 上传流程改为 123云盘分片上传
  - 添加上传进度显示

### 步骤 6：数据库迁移

- 已有 `cad_file_url` 字段可直接复用
- 新增可选字段 `storage_provider` 标识存储来源

### 步骤 7：测试

1. 单元测试：Token 刷新、上传流程
2. 集成测试：实际上传 500MB 文件
3. 回归测试：已有功能不受影响

## 风险与解决方案

| 风险 | 解决方案 |
|------|----------|
| 123云盘 API 调用频率限制 | 使用 SDK 内置的重试机制，必要时增加指数退避 |
| 大文件上传网络中断 | SDK 支持断点续传和分片重试 |
| Token 过期 | SDK 自动刷新（提前 5 分钟） |
| 下载流量费用 | 购买 VIP 或分享流量包 |
| 文件迁移 | 保留 Supabase 旧文件只读，新文件写入 123云盘 |
