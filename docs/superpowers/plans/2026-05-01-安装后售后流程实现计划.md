# 安装后售后流程实现计划

依据设计文档：`docs/superpowers/specs/2026-05-01-安装后售后流程设计.md`

## Goal

在安装流程结束后增加一个可选的"售后"阶段，支持：
1. 安装完成时选择"直接完成"或"进入售后"
2. 售后阶段支持添加售后反馈记录
3. 售后完成后订单归档
4. 数据看板、客户详情页、订单详情页、安装详情页均展示售后阶段

## Architecture

新增一个 order status `in_after_sales`，作为 `in_install` 和 `completed` 之间的可选中间状态。
售后数据存储在 installations 表的 `after_sales_feedback` JSON 数组字段中。
