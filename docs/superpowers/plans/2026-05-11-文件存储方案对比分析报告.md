# 文件存储方案对比分析报告

## 项目需求

- 支持 CAD 文件上传（.dwg, .dxf, .pdf 等）
- 文件大小限制需提升至 **500MB**
- 当前使用 **Supabase Storage**，容量不足
- 要求**免费或极低成本**

---

## 重点方案分析

### 1. Cloudflare R2（推荐指数：⭐⭐⭐⭐⭐）

**优势：**
- 每月 **10GB 存储免费**
- **出口流量完全免费**（下载不花钱）
- S3 兼容 API，生态丰富
- 单文件最大支持 **5TB**
- 全球 CDN 加速

**劣势：**
- 需绑定信用卡/PayPal（仅验证身份）
- 国内访问需绑定自定义域名（需域名托管在 Cloudflare）
- 免费额度超量后：存储 $0.015/GB/月

**成本估算（月度）：**
| 使用量 | 费用 |
|--------|------|
| 10GB 以内 | **$0（免费）** |
| 50GB 存储 | $0.6（约 ¥4.3） |
| 100GB 存储 | $1.35（约 ¥9.7） |
| 500GB 存储 | $7.35（约 ¥53） |

**接入方式：**
- 使用 AWS SDK for JavaScript (`@aws-sdk/client-s3`)
- 或通用 S3 兼容库

---

### 2. 七牛云 Kodo（推荐指数：⭐⭐⭐⭐）

**优势：**
- 每月 **10GB 存储 + 10GB 下载流量免费**
- 国内访问速度快
- S3 兼容 API
- 有免费 CDN 加速

**劣势：**
- 需实名认证
- 超出免费额度后费用较高
- 功能有一定限制

**成本估算（月度）：**
| 使用量 | 费用 |
|--------|------|
| 10GB 以内 | **¥0（免费）** |
| 50GB 存储 | 约 ¥5-10 |
| 100GB 存储 | 约 ¥15-25 |

---

### 3. Supabase 付费升级（推荐指数：⭐⭐⭐）

**优势：**
- 无需改动代码（已接入）
- 专业版 $25/月 包含 100GB 存储
- 文件大小限制可提升至 5GB

**劣势：**
- 付费固定月费
- 超出 100GB 后 $0.021/GB

**成本估算：**
| 方案 | 费用 |
|------|------|
| 专业版 | $25/月（约 ¥180） |
| 超出 100GB | $0.021/GB |

---

### 4. MinIO 自建（推荐指数：⭐⭐）

**优势：**
- 完全免费开源
- 数据完全自主可控
- S3 兼容

**劣势：**
- 需要一台服务器（最低配置约 ¥50-100/月）
- 需自行维护、备份、扩容
- 无 CDN，下载速度取决于服务器带宽

---

## 推荐方案

### 首选：Cloudflare R2

**理由：**
1. **真正的免费** - 10GB 存储 + 出口流量全免
2. **500MB 文件完全支持** - 单文件限制 5TB
3. **成本极低** - 即使超量，费用也非常低
4. **技术成熟** - S3 兼容，SDK 丰富

**实施步骤（供参考）：**
1. 注册 Cloudflare 账号
2. 绑定支付方式（信用卡/PayPal，仅验证）
3. 创建 R2 存储桶
4. 生成 S3 兼容 API 密钥
5. 安装 `@aws-sdk/client-s3`
6. 修改上传代码使用 R2 Endpoint

### 次选：七牛云

如果担心 Cloudflare 国内访问问题，七牛云是更好的国内替代方案。
