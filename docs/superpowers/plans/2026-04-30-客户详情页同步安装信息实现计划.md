# 客户详情页同步展示安装信息实现计划

依据设计文档：`docs/superpowers/specs/2026-04-30-客户详情页同步安装信息设计.md`

## 变更清单

### 1. 服务端数据获取 (`app/(dashboard)/customers/[id]/page.tsx`)

在 `getCustomer` 中，获取到订单列表后，若存在订单，通过 `order_id` 查询关联 installation：

- 查询字段：`id, status, scheduled_date, feedback, order_id`
- 使用 `.maybeSingle()`（并非所有订单都有 installation）
- 将 `installation` 一并返回给页面组件
- 页面组件将 `installation` 作为 prop 传给 `CustomerDetailClient`

### 2. 客户端展示 (`app/(dashboard)/customers/[id]/customer-detail-client.tsx`)

- 在 `CustomerDetailClientProps` 中新增 `installation` 字段
- 在 `pending_shipment` 区域（已分配安装师傅后）：
  - 在现有"已分配安装师傅"文案下方，新增"预计出货日期"展示
  - 新增"安装反馈记录"列表（遍历 `installation?.feedback`）
  - 每条记录展示 `content` + `date`
  - 无记录时显示 "暂无安装反馈"
  - 新增跳转链接 "去安装管理查看详情 →"
- 在 `in_install` 区域：
  - 在现有"安装进度"文案下方，新增"预计出货日期"展示
  - 新增"安装反馈记录"列表（遍历 `installation?.feedback`）
  - 每条记录展示 `content` + `date`
  - 无记录时显示 "暂无安装反馈"
- 在 `completed` 区域：
  - 在现有"订单已完成"文案下方，新增"安装反馈记录"列表（归档查看）
- 跳转链接文案统一为"去安装管理查看详情 →"

## 实现步骤

1. 修改 `page.tsx`，增加 installation 查询逻辑
2. 修改 `customer-detail-client.tsx`，接收 installation prop 并在对应区域渲染
3. 本地验证：访问一个 `in_install` 状态的客户详情页，确认安装信息正确展示
4. 验证 `completed` 状态客户，确认反馈记录归档展示

## 测试要点

- `pending_shipment` 状态且已分配安装师傅 + 存在 installation + feedback：展示反馈列表
- `pending_shipment` 状态且已分配安装师傅 + 无 feedback：显示"暂无安装反馈"
- `in_install` 状态且存在 installation + feedback：展示反馈列表
- `in_install` 状态且存在 installation 但无 feedback：显示"暂无安装反馈"
- `in_install` 状态但无 installation（数据异常）：不报错，正常展示其他信息
- `completed` 状态：展示完结信息 + 反馈记录
- 其他状态：不受任何影响
