# 三模块融合单工作线设计

## 目标

订单状态机打散融入"客户管理 + 方案管理 + 安装管理"三个模块，串联成一条完整工作线。**不保留独立的"订单管理"页面**作为工作流入口。

## 订单状态机（唯一流程引擎）

```
pending_dispatch → pending_design → designing → pending_order → pending_payment → pending_shipment → in_install → completed
```

## 三模块职责分工

### 1. 客户管理（/customers）—— 全流程主入口 + 前半段操作

**客户列表页（/customers）**：
- 维持现有逻辑——"订单跟进"显示有进行中订单的客户
- 点击客户进入详情页

**客户详情页（/customers/[id]）**—— 取代原"订单详情页"成为全流程总览：

| 订单状态 | 显示内容 |
|---------|---------|
| pending_dispatch | **派单给设计师**操作（核心操作区） |
| pending_design | 显示派给了谁 + 等待接单状态 |
| designing | 显示"设计方案进行中"→ **跳转方案详情页** |
| pending_order | 显示"等待下单" + **跳转方案详情页**操作 |
| pending_payment | 显示"等待打款"（老板角色显示确认打款） |
| pending_shipment | 显示"等待出货"（设计师操作出货时间+指派安装） |
| in_install | 显示"安装中"→ **跳转安装管理页** |
| completed | 显示"已完结"归档信息 |

**所有状态都显示 `OrderStatusFlow` 进度条**，让用户一眼看到全流程位置。

### 2. 方案管理（/designs）—— 设计中段操作

**方案列表页（/designs）**：
- 显示"分配给我的设计任务"（订单状态为 `pending_design`/`designing`/`pending_order`）
- 展示：订单号 + 客户名 + 当前阶段 + 更新时间
- 点击进入方案详情页

**方案详情页（/designs/[id]）**：
- 顶部：**订单进度上下文卡片**（订单号 + 当前阶段 + 签单金额 + 关联客户）
- 中间：设计方案数据（面积、描述、酷家乐链接、CAD文件）
- 底部操作按钮（按状态显示）：
  - `designing`（分配给你的）：**编辑方案表单** + 提交方案按钮
  - `pending_order`：**下单到工厂**操作（填写工厂信息）

### 3. 安装管理（/installations）—— 后半段操作

**安装列表页（/installations）**：
- 订单进入 `in_install` 时自动创建 installation 记录
- 安装师傅在这里查看和更新安装进度
- 显示关联订单号

**安装详情页（/installations/[id]）**：
- 展示安装信息 + 关联设计方案
- 更新安装状态（在安装管理内完成，不影响订单状态机）
- 当 installation_status 变为 `installed` 时，订单自动完结

## 模块间跳转规则

```
客户详情页（总览入口）
  ├─ pending_dispatch → 派单 → 跳转"等待设计师接单"
  ├─ designing → "查看设计方案" → 方案详情页
  ├─ pending_order → "去下单" → 方案详情页
  ├─ pending_shipment → "填写出货" → 客户详情页（出货操作区）
  ├─ in_install → "查看安装进度" → 安装管理页
  └─ completed → "查看安装详情" → 安装管理页
```

```
方案详情页
  └─ 设计完成 → 提交方案 → 跳转客户详情页（继续流程）
```

## API 调整

- `accept`：接单成功 → 自动创建 design → 通知设计师去方案管理
- `submit-design`：提交方案 → 同步 design status → 通知销售去客户管理继续
- `set-shipment`：填写出货+指派安装 → 自动创建 installation → 通知安装师傅去安装管理
- `update-install`：安装进度更新 → 保持安装管理独立
- `complete`：安装完成 → 订单完结

## 废弃内容

- `/orders` 页面作为独立工作流入口（可保留查看，但不再是主流程）
- 订单详情页（`/orders/[id]`）的流程操作功能 → 全部迁移到客户详情页
- 侧边栏的"订单管理"入口 → **移除**

## 导航结构

```
侧边栏：
  数据看板
  客户管理（主入口）
  方案管理（设计任务）
  安装管理（安装任务）
  已完成订单（归档）
  消息中心
  账号管理（管理员）
```
